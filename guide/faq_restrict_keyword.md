## FAQ: restrict 关键字
`restrict` 是 **C99 标准**里新引入的一个关键字，主要用于 **指针的别名优化（aliasing optimization）**。

简单说：
它告诉编译器：**通过这个指针访问的内存区域，不会被其他指针所别名(alias)，即不会被别的指针同时指向并修改。**

---

### 举个例子

```c
void copy(int *restrict dst, const int *restrict src, size_t n) {
    for (size_t i = 0; i < n; i++) {
        dst[i] = src[i];
    }
}
```

这里 `restrict` 表示：

* `dst` 指向的内存区域 **只会** 通过 `dst` 访问；
* `src` 指向的内存区域 **只会** 通过 `src` 访问；
* 所以，编译器可以假设 `dst` 和 `src` 不会重叠（否则会违反 `restrict` 的语义）。

这样编译器就可以放心地做一些优化，比如：

* 提前加载 `src[i]`，存到寄存器里，多次使用；
* 指令流水线更高效，因为不用担心 `dst[i] = ...` 会影响到 `src[j]` 的值。

---

### 如果没有 `restrict`

没有 `restrict` 的情况下，编译器必须保守地认为 `dst` 和 `src` 可能是同一块内存，优化时就要小心，避免提前读写破坏结果。

例如：

```c
int a[10];
copy(a, a+1, 5);
```

这里就发生了 **重叠内存拷贝**，如果使用 `restrict` 声明，那么行为是 **未定义的**（因为你违反了承诺）。

---

### 总结

* `restrict` 的作用：**允许更激进的优化**，提高性能。
* 限制：

  * 只能用于指针（而不是普通变量）。
  * 如果违反承诺（即两个 `restrict` 指针实际指向同一块内存），程序行为 **未定义**。
